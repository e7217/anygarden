# 에이전트 생성과 설정 개선 조건

기존 승인된 제품 UI/UX 개편과 2026-09-26 추가 개선 요청을 적용한다.
생성 폼을 머신 페이지에서 독립시켜 설정 상태, 검증, 저장 순서를 한 컴포넌트에서 관리한다.

| 화면·조건 | 기본값 | 표시·동작 |
| --- | --- | --- |
| 모든 엔진 생성 | 이름 필수, 설명 선택, 권한 표준 | 이름·200자 설명·엔진·권한·프로젝트별 참여 룸을 표시 |
| 머신에서 생성 | 선택 머신 | 해당 머신의 온라인 연결, 엔진 지원, 수용량을 서버에서 확인하고 첫 배치에 반영 |
| API에서 머신 미지정 | 자동 배치 | 기존 적합 머신 선택 유지 |
| Pi 생성 | 기본 공급자 연결 | 공급자와 모델 필수. 직접 연결 선택 시에만 URL·프로토콜·인증 표시 |
| Pi 권한 | 표준 도구 사용 | 제한 권한은 읽기 도구 목록을 제한하며 OS 샌드박스를 제공하지 않는다는 점을 표시 |
| Pi 외 엔진 | 엔진 기본 모델 | 지원되는 모델·추론 선택지만 표시 |
| 역할 지침 추가 | 닫힘, 빈 지침 | 펼친 경우 AGENTS.md를 초기 생성 요청에 포함 |
| 생성 시 워크스페이스 | 자동 관리 작업 공간 | 임의 호스트 경로 입력은 제공하지 않음. 외부 작업 공간은 방별 연결과 머신의 동의가 필요한 기존 모델을 설명 |
| 생성 시 활동로그 | 생성 후 기록 | 입력 대신 생성 후 설정에서 확인할 수 있음을 안내 |
| 생성 완료 | 생성된 에이전트 설정 열기 | 설명·권한·방·파일·책임·작업·활동까지 다음 설정 경로 유지 |
| 설정 | 패널 유지 | 데스크톱은 모든 섹션 바로가기, 모바일은 섹션 선택 메뉴. 활동 이동 시 접힌 로그 자동 펼침. 이동해도 편집 상태 유지 |
| 설정의 외부 작업 공간 | 기존 연결 조회 | 소속 방의 연결 상태·읽기/쓰기·만료를 확인. 등록된 작업 공간에 연결 요청, 방·관리자 승인, 로컬 동의 확인, 철회를 기존 API 절차대로 제공 |

권한은 생성 후 별도 요청으로 적용하면 첫 실행에 늦을 수 있으므로 생성 트랜잭션에서 저장한다.
새 머신 선택 필드는 초기 배치를 지정하며, 이후 장애 복구는 기존 restart_policy를 유지한다.
검증은 생성 요청의 필드 전달, 엔진별 숨김 필드 초기화, 섹션 이동 시 편집 상태 보존,
생성 시 권한·머신 선택 및 잘못된 선택의 원자적 거부를 포함한다.
