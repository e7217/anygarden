기존 공용 질문·승인 카드와 API를 재사용한다. 넓은 화면의 별도 상세 열은 좁은 화면과 다른 경로를 만들고, 한 항목만 마운트하는 방식은 답변 초안을 잃을 수 있다. 동일한 펼침 목록을 모든 화면에 사용하고, 각 항목의 상세를 유지해 접기와 새로고침에도 초안이 남게 한다.

요약은 프로젝트·방·유형·제목 2줄·상태·갱신 시각이다. 상태는 작업 진행과 실행 disposition을 구분한다. 각 그룹은 최근 갱신 순서이며, 기본 본문에는 긴 질문·결과·해시가 노출되지 않는다. 프로젝트/유형 필터, 오류·로딩·빈 상태·접근 불가 상태를 유지한다. 초안은 컴포넌트 마운트를 유지하는 동안 보존하며 페이지를 떠나는 경우 영구 저장하지 않는다.

검증: 직접 링크와 필터, 초안 유지, 취소 분류, 답변/승인 권한의 컴포넌트·브라우저 테스트. 실서비스에서 375/768/1024/1440px, 한영, 라이트다크를 묶어서 확인한다.

## 검증 결과

빌드 통과. 받은편지함·공용 카드·상태 분류 테스트 23개 통과. 신규 Playwright 2개에서 모바일/데스크톱의 키보드 펼침, 새로고침 후 답변 초안 보존, 직접 링크 자동 열기를 검증했다.

실제 서비스에서 네 화면 폭의 한영·라이트다크 조합을 점검하다 마지막 데스크톱 구간에서 소스 변경에 따른 HMR로 브라우저가 작성 중이던 테스트 초안이 초기화됐다. 소스 변경을 멈춘 뒤 모바일/데스크톱 라이트다크 4개 조합을 재확인했고 모든 초안 보존·가로 넘침·JavaScript 예외 검사 및 직접 링크 확인이 통과했다. 별도 재현 가능한 E2E에서도 새로고침과 초안 보존이 통과했다.
