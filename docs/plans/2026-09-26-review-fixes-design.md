# UI·실행 흐름 리뷰 후속 수정

2026-09-26 전체 리뷰의 14개 항목과 수정 우선순위를 사용자가 승인했다. 기존 작업 트리의 개선을 보존하면서 실제 실패 시나리오를 해결한다.

## 적용 조건

| 흐름 | 조건 | 표시·동작 |
| --- | --- | --- |
| 머신 상세 | 선택한 머신의 데이터 조회 중 | 이전 머신의 상세를 노출하지 않음. 에이전트 생성·엔진 작업 대기 |
| 머신 상세 | 현재 선택과 응답 대상이 일치 | 같은 요청에서 읽은 에이전트·엔진·활동을 함께 표시 |
| 머신 상세 | 요청 실패 | 실패 상태와 재시도 제공. 빈 목록으로 오인하지 않게 함 |
| 머신 상세 | 이전 선택의 지연 응답 | 화면 상태를 변경하지 않음 |
| 워크스페이스 | 서버·엔진·권한·머신이 지원하지 않는 조합 | 지원하지 않는 이유 표시. 완료 불가능한 연결 입력을 노출하지 않음 |
| 워크스페이스 | 기존 연결·승인 요청 존재 | 상태 조회와 권한에 맞는 해제·승인 경로 보존 |
| 연결 등록 | 웹에서 발급한 머신과 토큰 | 기존 머신에 연결하는 설정을 저장하고 이후 토큰 재입력 없이 재실행 |
| 에이전트 생성 | DB 저장 성공, 실행 준비 실패 | 생성 결과와 실행 상태를 분리. 같은 생성의 재시도가 중복을 만들지 않게 함 |
| 머신 배치 | 대기·시작·실행·정지 중 예약 존재 | 수용량에 포함. 검사와 예약을 원자적으로 처리 |
| 에이전트 수정 | 저장 성공, 후속 목록 조회 실패 | 성공 응답을 화면에 반영. 조회 실패와 저장 실패 구분 |
| 모델·연결 변경 | 종속 옵션 또는 이전 요청 무효화 | 추론 값을 재검증하고 이전 모델 조회 결과 폐기 |
| 탐색 | 모바일 패널 열림 | 패널로 포커스 이동, 배경 비활성화, Tab 제한, Escape와 닫기 복귀 |
| 탐색 | 사이드바 접힘 | 사이드바에서 열린 메뉴도 닫음 |

## 구현 순서

1. 생성·배치의 상태 전이와 실패 재시도, 워크스페이스 지원 계약, 머신 연결 저장 경로를 수정한다.
2. 머신 상세를 대상별 요청 상태로 관리하고 오래된 응답 및 작업 후 지연 갱신을 차단한다.
3. 모델·권한의 저장 상태와 요청 취소를 정리한다.
4. 공통 크기 토큰·CSS 계층·드로어 동작을 적용한다. 기존 언어 및 접기·펼치기 위치를 유지한다.
5. 각 실패 재현을 회귀 테스트로 바꾸고 전체 프론트 테스트·빌드, 관련 백엔드·CLI 테스트, 실제 반응형 브라우저를 검증한다.

## 검증 원칙

실제 사용자 머신이나 에이전트의 생성·정지·권한 승인은 검증용으로 변경하지 않는다. 메모리 DB·임시 설정 저장소로 실패·재시도·동시 예약을 검증한다. UI의 성공 응답 대역 외에 서버와 기본 데몬의 실제 지원 조합도 확인한다. 원격 실행을 실제로 검증하지 못했다면 최종 결과에 구분하여 기록한다.
