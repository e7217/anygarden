# 대화로 워크스페이스 관리하기

워크스페이스 도구를 켠 에이전트에게 말로 부탁하면, 방·작업·루틴·목표를 조회하고 바꿉니다(#938).

> "@운영봇 이 프로젝트 아래 QA 서브룸 만들고 테스터 에이전트 넣어줘"
> "@운영봇 매일 아침 9시에 어제 실패한 작업을 정리하는 루틴 만들어줘"

## 켜는 방법

관리자가 **에이전트 설정 → 개요 → 워크스페이스**에서 켭니다.

- **대화로 워크스페이스 관리**: 에이전트에게 `workspace_query`와 `workspace_action` 도구가 보입니다. 꺼져 있으면 도구 목록에 나오지 않습니다.
- **새 에이전트 제안**: 에이전트가 새 에이전트 고용을 제안할 수 있습니다. 워크스페이스 도구가 켜져 있어야 켤 수 있습니다.

두 설정은 바로 적용되며 에이전트를 재시작하지 않습니다.

## 누구의 권한으로 동작하나

**에이전트에게 말을 건 사람의 권한**으로, 그 대화 턴 안에서만 동작합니다.

- 그 사람이 웹 화면에서 할 수 없는 일은 에이전트도 할 수 없습니다. 볼 수 없는 방은 조회되지 않고, 권한이 없는 변경은 거부됩니다.
- 다른 에이전트가 부탁해서 시작된 턴, 서버 알림(작업 배정 등)으로 시작된 턴, 게스트의 메시지, 공유(연합) 방에서는 동작하지 않습니다. 대신 해 줄 사람이 없기 때문입니다.

## 바로 실행되는 일과 승인이 필요한 일

| 동작 | 처리 |
|---|---|
| 하위 방·프로젝트 방 만들기, 방에 에이전트 추가 | 바로 실행 |
| 작업 만들기·다시 배정하기 | 바로 실행 |
| 루틴·목표 일시 정지·재개 | 바로 실행 |
| 루틴 만들기, 목표 시작하기 | 방에서 승인 |
| 방 보관 | 방에서 승인 |
| 새 에이전트 고용 | 관리자 승인 |
| 공유 채널 만들기·연결 | 제공하지 않음(관리자 화면에서) |

승인이 필요한 일은 에이전트가 방에 **승인 필요** 카드를 올립니다.

- 부탁한 사람이나 관리자가 **승인** 또는 **거절**을 누릅니다. 새 에이전트 고용은 관리자만 승인할 수 있습니다.
- 승인하면 저장된 요청이 **승인한 사람의 권한으로 한 번만** 실행됩니다. 두 번 눌러도 다시 실행되지 않습니다.
- 60분 안에 결정하지 않으면 만료되고 실행되지 않습니다.
- 카드에는 승인하면 실행될 값이 모두 보입니다. 요약만 보고 승인하지 마세요.
- 결과(완료·실패·거절)는 서버 알림으로 에이전트에게 전달되고, 에이전트가 다시 깨어나 알려 줍니다. 이어지는 턴은 **처음 부탁한 사람의 권한**으로 동작합니다. 관리자가 승인했더라도 에이전트가 관리자 권한을 얻지 않습니다.
- 실행은 승인한 사람의 권한으로 하므로, 관리자가 승인한 루틴·목표의 소유자는 그 관리자가 됩니다.
- 실행 도중 서버가 멈춰 결과를 모르는 요청은 15분 뒤 "결과 알 수 없음"으로 실패 처리됩니다. 다시 요청하기 전에 실제로 반영됐는지 확인하세요.

## `/goal`·`/routine` 초안 받기

입력창에 설명을 붙여 쓰면 에이전트가 초안을 쓰고, 방에 초안 카드가 올라옵니다(#947, #948). 워크스페이스 도구를 켜지 않은 에이전트도 초안을 쓸 수 있습니다.

> `/goal 검색 응답을 1초 안으로 줄이기`
> `/routine @운영봇 매일 아침 9시에 어제 실패한 작업 정리`

| 입력 | 초안을 쓰는 에이전트 | 루틴 담당자 |
|---|---|---|
| `/goal 설명` | 방의 대표 에이전트 | — |
| `/routine @에이전트 설명` | 지명한 에이전트 | 그 에이전트 |
| `/routine 설명` (에이전트 한 명) | 그 에이전트 | 그 에이전트 |
| `/routine 설명` (대표 에이전트가 있는 방) | 대표 에이전트 | 대표가 제안(폼에서 변경 가능) |
| `/routine 설명` (대표 없이 여럿) | 입력창에서 @로 지정하라고 안내 | — |

- 설명 없이 `/goal`·`/routine`만 쓰면 지금처럼 빈 폼이 열립니다.
- 카드는 값을 읽기 쉽게 보여 줍니다. 목표는 방식·지표·목표치·마감·평가 명령·예산을, 루틴은 담당자·주기(사람 말과 원래 식)·시간대·지시문·보고 방을 보여 줍니다.
- **[만들기]** 한 번으로 만들어집니다. **[폼에서 수정]**은 초안 값이 채워진 폼을 열고, 제출하면 고친 값으로 한 번만 만듭니다. **[거절]**하면 만들지 않습니다.
- 승인 규칙은 위와 같습니다: 요청한 사람이나 관리자가, 승인한 사람의 권한으로, 60분 안에 결정합니다. 목표는 평가 명령이 대표 에이전트 머신에서 실행되므로 그 머신의 소유자나 관리자만 만들 수 있습니다.
- 루틴의 cron 시간은 요청한 사람 브라우저의 시간대로 채워집니다. 카드에 시간대가 보입니다.
- 에이전트는 초안 요청으로 시작된 그 턴에서만 초안을 낼 수 있습니다(`propose_goal`·`propose_routine`). 서버가 검증에 실패한 초안은 카드로 만들지 않고 에이전트에게 돌려보내 고치게 합니다.
- 에이전트가 초안 없이 턴을 끝내면 "초안이 만들어지지 않았습니다" 안내와 **[빈 폼 열기]** 버튼이 뜹니다.

## 새 에이전트 고용

- **새 에이전트 제안**이 켜진 에이전트만 제안할 수 있습니다. 직함이나 역할(대표·운영 리더)과 관계없습니다.
- 새 에이전트의 권한 수준은 제안한 에이전트보다 높을 수 없습니다. 더 높게 요청하면 거부됩니다. 승인 전에 제안한 에이전트의 권한이 낮아졌다면 승인 시점의 권한으로 낮춰서 만듭니다.
- 새 에이전트는 워크스페이스 도구와 고용 권한을 받지 않습니다. 필요하면 관리자가 따로 켭니다.

## 에이전트의 자기 지침 변경

목표(이전 이름: 캠페인)의 회고는 에이전트 자신의 AGENTS.md와 스킬을 **승인 없이** 고칩니다(#930). 변경은 모두 지침 리비전으로 남고, **지침 변경 이력**에서 되돌릴 수 있습니다. 이 정책도 동작별 정책표(`anygarden/workspace/policy.py`)에 함께 적혀 있습니다.
